# 📌 Featured Projects

## 🤖 Multimodal Human Action Recognition

**Python • PyTorch • CNN • BiLSTM • ST-GCN**

An end-to-end multimodal deep learning system for recognizing human activities using **skeleton and IMU sensor data**.

### Highlights
- Processed **861K+ skeleton frames**
- Processed **4.5M+ IMU data points**
- Covered **27 human activity classes**
- Built both **ST-GCN** and **CNN + BiLSTM** architectures
- Applied **late fusion** to combine modalities
- Achieved **95.3% overall accuracy**

### Results

| Model | Accuracy |
|-------|----------|
| CNN + BiLSTM | 87.4% |
| ST-GCN | 91.2% |
| Late Fusion | **95.3%** |

## 🌫️ De-Hazify — Image Data Quality Enhancement

**Python • PyTorch • OpenCV • U-Net**

A deep-learning based image restoration pipeline designed to enhance images affected by atmospheric haze.

### Highlights
- Trained using the **RESIDE-ITS dataset**
- Worked with **13,990 paired hazy/clear images**
- Implemented a **U-Net based restoration pipeline**
- Added controllable **dehazing intensity**
- Evaluated performance using **PSNR and SSIM**
- Achieved:
  - **+3.8 dB PSNR**
  - **+0.041 SSIM**
